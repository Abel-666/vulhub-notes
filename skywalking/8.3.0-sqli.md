开启环境：
```
docker compose up -d
```
访问页面：
```
http://localhost:18080
```

发送请求：
```
POST /graphql HTTP/1.1

{
    "query":"query queryLogs($condition: LogQueryCondition) {
  queryLogs(condition: $condition) {
    total
    logs {
      serviceId
      serviceName
      isError
      content
    }
  }
}
",
    "variables":{
        "condition":{
            "metricName":"sqli",
            "state":"ALL",
            "paging":{
                "pageSize":10
            }
        }
    }
}
```
可以看到SQL语句出错
`metricName`参数的值被拼接到`from`后面
