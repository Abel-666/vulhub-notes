开启环境：
```
docker compose up -d
```
访问页面：
```
http://localhost:18080
```
首先需要创建一个普通账户
邮箱：`example@example.com`
密码：`a123123123`

然后发送请求进行登录：
```
curl -i -s -k -XPOST --data-binary "email=example%40example.com&password=a123123123" http://localhost:18080/api/v1/passport/auth/login
```
服务器回返回当前用户的认证信息`auth_data`":`
```
"auth_data":"ZXhhbXBsZUBleGFtcGxlLmNvbTokMnkkMTAkMUVYTW1MY3F2OXZWL2NzaUh4MWJHdTRqMFBhN0FlLlFUelVnU3oyYjZPTlM3c0hXR1Z0bXE="
```
发送数据包将auth_data替换到Authorization头中：
```
GET /api/v1/user/info HTTP/1.1
Authorization: ZXhhbXBsZUBleGFtcGxlLmNvbTokMnkkMTAkMUVYTW1MY3F2OXZWL2NzaUh4MWJHdTRqMFBhN0FlLlFUelVnU3oyYjZPTlM3c0hXR1Z0bXE=
```

然后只需要带上Authorization头就可以使用所有管理员API
