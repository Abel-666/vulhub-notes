开启靶场：
```
docker compose up -d
```
有两个版本的ecshop
2.7.3版本：
```
http://localhost:18080
```
3.6.0版本：
```
http://localhost:8081
```
依次安装
数据库地址：`mysql`
数据库账户和密码：`root`
数据库名随意填写，但是两个数据库名不可以一样
